Project Name: E-Commerce Sales Analysis
Project Objective: This project analyzes sales made by people from different countries across five categories.
Tools & Technologies Used: 
- Excel and Power Query for ETL processing
- Power BI Desktop for building interactive dashboards
- DAX for building custom business metrics
Key Business Insights:
- The t-test confirmed that purchasing behaviour and spending habits of male and female customers do not differ significantly
- The goal seek analysis showed that increasing transaction volume increases revenue
- The regression analysis proved that higher product prices yield higher revenue
How To Interact With This Project:
- Download the file located in models/Sales Analytics Report.pbix
- Open the file using PowerBI Desktop to view the interactive dashboard and DAX measures
